# NOT included here on purpose: tensorflow / keras.
#
# vision_emotion.py only imports TensorFlow lazily, inside
# _EmotionClassifier._load(), and only if a real model file is found at
# LILY_EMOTION_MODEL_PATH. If you don't set that env var, the emotion
# classifier runs in graceful no-signal fallback mode and TensorFlow is
# never imported at all -- so it's safe to run this file as-is even in
# a venv that doesn't have TensorFlow installed.
#
# If/when you're ready to wire in your real trained emotion model:
# install a TensorFlow version that matches what your Features 5 & 6
# project already uses in THIS venv, rather than an unpinned version --
# mixing TF/Keras major versions in one environment breaks mediapipe,
# scikit-learn, and streamlit (numpy/protobuf version conflicts).
#
# Check what you already have first:
#   python -c "import tensorflow as tf; print(tf.__version__)"
# Then install the matching version explicitly, e.g.:
#   pip install tensorflow==2.14.0 "numpy<2.0,>=1.23.5" "protobuf>=3.20.3,<4"
